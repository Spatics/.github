# SPATICS GitHub profile

Public presentation assets for the [SPATICS organization](https://github.com/Spatics).

GitHub displays `profile/README.md` on the organization’s public Overview page. The profile links to public SPATICS product information, design services and contact channels.

## Editing

Keep images in `profile/assets`, use absolute public image URLs in the profile, and increment the minor version in `VERSION` for each revision. Preserve accurate development and beta status when updating the copy. This repository does not contain product source code.
