### Circute.AI

An AI design copilot inside **KiCad**, connecting plain-language requests with supported schematic and PCB workflows.

- Describe the change in plain language.
- Get assistance with schematic edits, placement and routing.
- Review design checks and supported corrections.
- Keep or discard changes at checkpoints.

**In beta for invited users.**
